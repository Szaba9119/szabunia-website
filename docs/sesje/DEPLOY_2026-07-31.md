## 5. Jeśli coś pójdzie nie tak

```bash
git revert HEAD && git push origin main
```

Wszystkie zmiany są w jednym commicie, więc cofnięcie to jedna komenda.
Zmiany poza repo (szablony mailowe, kalkulator, cennik, CRM) **nie są objęte tym commitem**
i mają własne kopie w `01_Biznes/_System/_archiwum/`.
